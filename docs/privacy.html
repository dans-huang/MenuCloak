MenuCloak

Privacy Policy

Effective August 17, 2026

MenuCloak is a local macOS utility. It does not require an account with MenuCloak, does not include advertising or analytics, and does not operate a server that receives your focus text or Google Calendar data.

Google Calendar data

Connecting Google Calendar is optional. If you choose to connect, MenuCloak requests the Google Calendar read-only scope (https://www.googleapis.com/auth/calendar.readonly) to retrieve events from your primary calendar.

MenuCloak uses this data only to provide features that you initiate and can see:

  • Display an upcoming or ongoing event's title, start time, and location in the macOS menu bar.
  • Identify a Google Meet link associated with the relevant event so you can open it using MenuCloak's keyboard shortcut.
  • Ignore all-day, cancelled, and declined events and restore your focus text when no event qualifies.

How data is stored

Your Google OAuth refresh credentials are stored locally in macOS Keychain. Calendar event data is fetched directly from Google, held temporarily in the app's memory, and is not written to MenuCloak servers. MenuCloak does not sell, share, transfer, or use Google user data for advertising, analytics, credit decisions, or training generalized artificial intelligence models.

Data sharing

MenuCloak does not disclose Google user data to third parties. Your Mac communicates directly with Google's OAuth and Calendar API services to provide the connected feature.

Retention and deletion

Event data remains only in app memory and is replaced as Calendar information refreshes or when MenuCloak quits. Select Disconnect in MenuCloak to delete its saved Google credentials from macOS Keychain. You can also revoke MenuCloak's access at any time from your Google Account's third-party connections page.

Google API Services User Data Policy

MenuCloak's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Focus text and local settings

Your focus text and MenuCloak preferences are stored locally using standard macOS preferences. MenuCloak does not transmit them to the developer.

Changes to this policy

If MenuCloak's data practices change, this page will be updated before the new practices take effect. Material changes involving Google user data will also be reflected in the app and its consent information as required.

Contact

Questions or privacy requests can be sent to dd09153@gmail.com or opened as an issue in the MenuCloak GitHub repository.
